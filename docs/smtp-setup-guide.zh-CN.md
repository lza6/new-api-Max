# 邮件(SMTP)配置小白教程

> 作用：让系统能给用户发「邮箱验证码」「重置密码」「消费通知」等邮件。
> 本文面向完全没有配过邮箱的新手，一步步照做即可。

## 一、需要准备什么

你只需要一个**支持 SMTP 的邮箱账号**。三选一（推荐第一个）：

| 方案 | 难度 | 说明 |
|------|------|------|
| **腾讯企业邮箱** | ⭐ | 免费，配置最省事，国内速度快 |
| **QQ 邮箱** | ⭐⭐ | 免费，需要「开启 SMTP + 生成授权码」 |
| **163 邮箱** | ⭐⭐ | 免费，同样要授权码 |

> 只要邮箱服务商支持「SMTP 协议」，都通用。原理一样：把邮箱的
> 「服务器地址 / 端口 / 账号 / 密码（授权码）」填进后台。

---

## 二、以 QQ 邮箱为例（新手最常用的免费方案）

### 第 1 步：QQ 邮箱里开启 SMTP

1. 登录 [QQ 邮箱](https://mail.qq.com) → 点「设置」→「账户」。
2. 往下翻到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」。
3. 把「**SMTP 服务**」打开。
4. 按提示用手机 QQ 发短信验证，**会给你一个「授权码」**（16 位字母，类似
   `abcdefghijklmnop`）。
5. **这个授权码要保存好**，它相当于邮箱密码（配到后台用这个，不是 QQ 密码）。

### 第 2 步：把这些值抄下来

| 配置项 | 填什么 |
|--------|--------|
| SMTP Server（服务器） | `smtp.qq.com` |
| SMTP Port（端口） | `465` |
| SMTP Account（账号） | 你的 QQ 邮箱地址，如 `123456789@qq.com` |
| SMTP Token（密码/授权码） | 第 1 步拿到的 16 位授权码 |
| SMTP From（发件人） | 留空即可（系统会自动用上面的账号邮箱） |
| SSL/TLS | 选 **SSL/TLS**（465 端口默认加密） |

### 第 3 步：填进系统后台

1. 登录管理员后台 → 左侧菜单「**系统设置**」。
2. 找到「**集成** → **邮件设置**」（英文界面是 Integrations → Email Settings）。
3. 按上表把 5 项填进去，保存。
4. 系统里「发送测试邮件」验证，收到就说明成功了。

## 三、163 邮箱的差异（只改三处）

| 配置项 | 163 填什么 |
|--------|-----------|
| SMTP Server | `smtp.163.com` |
| SMTP Port | `465` |
| SMTP Account | `xxx@163.com`（你的 163 邮箱） |
| SMTP Token | 163 的「授权码」（在设置→POP3/SMTP/IMAP 里开启并生成） |
| SSL/TLS | SSL/TLS |

> 开启流程：163 邮箱 → 设置 → POP3/SMTP/IMAP → 勾选开启 SMTP 服务 →
> 按提示发短信 → 拿到授权码。SMTP From 留空。

---

## 四、腾讯企业邮箱（推荐给正式网站）

1. 登录腾讯企业邮箱管理后台，创建一个邮箱账号，如 `no-reply@你的域名.com`。
2. 得到：
   - Server：`smtp.exmail.qq.com`
   - Port：`465`
   - Account：`no-reply@你的域名.com`
   - Token：该邮箱的**客户端专用密码**（开启「客户端设置→客户端专用密码」生成）
3. 后台「集成 → 邮件设置」填好，SMTP From 留空，SSL/TLS，保存。

## 五、常见问题（出现这些就是哪里没对）

| 报错 | 原因与解决 |
|------|-----------|
| `invalid SMTP account` | 账号邮箱没填对，或 SMTP From 填了个不是邮箱的字符串。**确保填的是完整邮箱（含 @ 和域名）**；SMTP From 一般留空即可 |
| `535 Authentication failed` / 登录失败 | Token 填错了。腾讯/QQ/163 要用「授权码 / 客户端密码」，**不是邮箱登录密码** |
| 超时 / `dial tcp` 超时 | 端口错了。国内一般用 465（SSL）；服务器在国内就没事 |
| 能连上但发不出 / 被拒 | 检查 SSL/TLS 是否选对：465 用 SSL/TLS，587 用 STARTTLS |

### 端口速查

| 端口 | 加密方式 | 常见服务商 |
|------|----------|-----------|
| 465 | SSL/TLS | QQ、163、腾讯企业邮（推荐） |
| 587 | STARTTLS | 大多数国际邮箱（Gmail 等） |
| 25 | 无加密（通常被封） | 不建议用 |

---

## 六、最后

- 配好后在邮件设置页点「**发送测试邮件**」，收到即成功；收不到看上面的常见问题表。
- 验证码邮件只有在「注册开启邮箱验证」时才发；若不需要邮箱验证，可以不开，不影响其他功能。
