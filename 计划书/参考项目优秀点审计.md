# 参考项目优秀点审计与应用建议

> 来源：Desktop\imagefree-2ai（听风AI · 多提供商 AI 图像生成网关 v19.0.0，生产级 2api）
>        Desktop\freebuff-2api（同族小型 2api 网关）
> 用途：从参考项目提炼可复用的优秀工程点，评估是否移植/借鉴到 new-api 网关
> 日期：2026-09-23

## 一、参考项目画像

- **imagefree-2ai**：Python 3.11 + React 管理面板，把多家图像生成上游聚合为 OpenAI 风格 `/v1/*` 接口。核心能力：
  多提供商自适应路由（MAB-EWMA 打分/降级/熔断）、号池自动化、代理池轮换、有界优先级队列 + Worker 池
  （270+ RPS）、Prometheus + 审计 + 告警 + WebSocket 实时日志 + OTel、SSE 任务事件流（Last-Event-ID
  断线补偿）、任务进度/取消/重试、数据治理（软归档/批量导出/成本预警/七维健康自诊断）、i18n 一致性测试、
  MCP Streamable HTTP + 聊天工具安全执行（预算门禁 402 + 破坏性命令黑名单 + 三态回滚）、Tauri 桌面自升级。
- **freebuff-2api**：同族小型项目，含上游本体源码与成品，规模较小。

## 二、可汲取优秀点清单（分级）

### A 级：高价值、可直接借鉴（推荐优先落地）

| # | 优秀点 | 参考实现 | new-api 落点 | 改造量/风险 |
|---|--------|----------|--------------|-------------|
| A1 | 成本预警 webhook（`IF_COST_ALERT_PCT=80`，幂等告警） | 用量达阈值触发 webhook | 新增"按日/按用户消费阈值告警 webhook"（管理端配置） | 中；纯后端+配置 |
| A2 | 七维健康自诊断（`/v1/admin/health-report`，一键导出 JSON/MD） | DB/Redis/上游/队列/存储/证书/延迟体检 | 新增 `GET /api/health/report`（数据库/磁盘/上游连通/版本/订阅任务状态）管理端一键导出 | 中；纯后端 |
| A3 | 任务软归档 + 批量导出（`IF_TASK_RETENTION_DAYS=90`，CSV BOM 中文表头/JSON，10 万行截断） | 终态任务到期退冷，详情可查 | 为使用/任务日志增加归档策略 + 管理端导出 | 中 |
| A4 | i18n 一致性测试（91 key 一致性测试锁定） | 测试断言 en/zh 等 key 集合一致 | 为 7 语言 locale 增加 key 集合一致性测试（防漏译回归） | 低；纯测试 |
| A5 | SSE 任务事件流断线补偿（Last-Event-ID） | 断线按事件 ID 重放 | 为任务事件流补 Last-Event-ID 续传 | 中 |

### B 级：参考借鉴（需适配定位差异）

| # | 优秀点 | 说明 | 应用建议 |
|---|--------|------|----------|
| B1 | 多提供商自适应路由（MAB-EWMA：成功率/时延/负载打分 + 熔断降级） | new-api 已有 channel affinity/健康分 | 可增强渠道健康分算法（EWMA 成功率 + 熔断冷却） |
| B2 | 代理池轮换（住宅+免费双源、递增冷却、每日限额重置） | 应对上游按 IP 风控 | new-api 渠道层可横向扩展"出口代理池/多 key 轮换"（googletranslate-2api 已具备） |
| B3 | 任务幂等取消 + 一键重试（mark_finished 防覆盖护栏 + worker 双检查点） | 异步任务健壮性 | new-api 异步任务（Midjourney/视频等）借鉴幂等取消护栏 |
| B4 | 聊天工具安全执行（PreToolUse 硬门禁 + 预算门禁 402 + 破坏性命令黑名单 + 三态回滚） | 工具调用安全护栏 | new-api 任务/工具插件借鉴"预算门禁 + 危险命令黑名单" |

### C 级：不建议 / 不适用
- 号池自动注册 + 签到（与 new-api 定位不符）
- Turnstile token 预取（专用上游）
- Tauri 桌面（new-api 已是 Electron；如需可参考自升级签名校验）
- 画廊/瀑布流相册（图像专用）

## 三、建议下一步
1. 请从 A/B 级中圈定 1-3 个方向；默认推荐组合：**A1 成本预警 + A2 健康自诊断 + A4 i18n 一致性测试**（低风险、高感知、可快速闭环）。
2. 圈定后按 TDD 落地：先出该功能方案 md → 红→绿单测 → 实现 → 前端(i18n/UI) → 发版 v1.3.x → CI(GHCR) → 生产部署 → 线上 E2E → 文档入库。
