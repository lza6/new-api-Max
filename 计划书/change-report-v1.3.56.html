2. 直觉（Why）——设计取舍

  • 语义阴影换名避险：颜色 token 用异名间接（--color-*: var(--*)）无自环；阴影初版同名自引用是隐性循环，仅靠级联顺序工作 → 运行时变量改名 --elevation-*，与既有模式一致、消除脆弱性（审查 P2-1）。
  • 暗色不靠更黑：黑阴影在暗底上会消失，暗色套增加 opacity + inset 0 1px 0 顶部微高光，边缘/浮起清晰（不默认全暗）。
  • axe 走真实路径：keys step-up 用例点菜单→Copy Key→弹窗，不是 mock 一个弹起来的样子；断言 violations 而非只跑渲染。
  • 死码门禁只防新增：存量 600+ 死码不清零（避免大范围误伤），CI 用基线对比——新增 key 红、存量永远不阻塞。
  • code-split 断言加固：vendor 拆分会让"至少 2 个非 index chunk"恒真；改为对 async/ 路由 chunk 设下限（审查 P2-3）。
