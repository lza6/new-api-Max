# P2-4 平台生态立项：技能市场 / Skill 进化闭环 / /v1/pricing 镜像

> 状态：**已立项（PROPOSED）** ｜ 日期：2026-09-21 ｜ 主项目：new-api v1.2.58
> 性质：战略级。按《下一步改进指南.md》§15「先立项再细化，不一次性铺开」。

## 一、背景与价值

- 参考集（1191 项）扫描结论：AI 需求侧全景中最具横向扩展价值的是「技能/插件市场 + 成本透明 + 日志证据闭环」。
- 项目已具备：`pkg/jsplugin` 插件运行时 + `plugins/tasks` 内置 20+ 上游适配 + 任务插件市场（marketplace sources/index）+ `plugin-sandbox` 前端组件 + 计费表达式（billingexpr）。
- 本立项把「插件消费侧」扩展到「平台生态侧」：让插件既可被本网关使用，也能被复用/定价/镜像。

## 二、范围（三个里程碑，各自独立可交付）

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 技能市场 | 现有 task-plugin marketplace 升级为「技能卡片 + 版本 + 评分 + 安装即用」；支持 admin 自托管源；安装走 P2-3 审批链（hash 绑定） | 端到端安装→审批→激活→执行；市场索引缓存可刷新 |
| M2 Skill 进化闭环 | 插件运行时遥测（调用成功率/耗时/错误类）回流市场卡片；作者可收到使用统计（脱敏） | 遥测采样率>0；统计仅聚合非敏感；与 perf_metrics 打通 |
| M3 /v1/pricing 镜像 | 站内模型定价以 billingexpr 表达式导出为标准 `/v1/pricing` 端点（价格镜像供第三方查询） | 表达式与镜像价一致；历史版本可回溯；无敏感渠道信息泄露 |

## 三、依赖与前置

1. M1 依赖 P2-3 审批链（已闭环 v1.2.58）+ marketplace 既有组件（复用）。
2. M2 依赖 P0-4 错误归因（已闭环）+ perf_metrics（既有）。
3. M3 依赖 billingexpr（既有，见 `pkg/billingexpr/expr.md`）。

## 四、风险与边界

- 市场索引为外部 URL（official/GitHub）：需校验来源白名单 + 防投毒（hash 固定，安装即审批）。
- 遥测脱敏：禁落 token/key/邮箱/IP 明细，只聚合计数与时延分布。
- /v1/pricing 镜像不得泄露渠道密钥与成本结构之外的经营数据。

## 五、执行方式（不一次性铺开）

- 按 M1 → M2 → M3 顺序各作独立批次；每个里程碑走「规划→实现→三库/前端验收→提交发行」SOP。
- 本立项文档为规划入口；里程碑细化文档在启动对应批次时产出（沿用《下一步改进指南.md》批次模板）。
