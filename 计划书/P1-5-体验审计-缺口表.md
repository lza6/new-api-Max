# P1-5 前端体验矩阵：反馈/加载/错误/空态 + a11y（审计缺口表）

> 批次：P1-5 ｜ 版本：v1.2.55 ｜ 日期：2026-09-21
> 原则：先真实盘点「已有覆盖」，只列**确凿缺口**，逐项修复并配回归测试，不制造伪需求。

## 一、审计范围与方法

- 范围：主流程六步（登录 → 选模型 → 对话/任务 → 看日志 → 充值 → 看账单）+ 通用组件层。
- 方法：
  1. 全 feature 扫描 `size="icon"` 按钮与 aria-label 覆盖（脚本逐文件核对）。
  2. 扫描绕过 `Button` 封装的手写 `<button>`。
  3. 核对异步操作按钮的 loading/disabled 防重（`isPending`/`isSubmitting`/`Loader2`）。
  4. 核对三态组件（`EmptyState`/`ErrorState`/`LoadingState`）在主流程页面的使用。
  5. 核对表单 label 关联、弹窗 Esc/focus（Base UI 内建）、i18n 覆盖。

## 二、基线核验表（已有覆盖，非本次改动）

| 主流程 | 点击反馈 | 加载态 | 错误态 | 空态 | 证据 |
|---|---|---|---|---|---|
| 登录 | 提交按钮 loading spinner + disabled 防重；WeChat 弹窗同样处理 | -（表单瞬时） | toast + FormMessage 字段错误 | - | `features/auth/sign-in/components/user-auth-form.tsx` |
| 选模型 | 选择后高亮/选中态 | 模型下拉 isModelLoading | - | - | `features/playground/components/input/playground-input-controls.tsx` |
| 对话/任务 | 发送按钮 `disabled={!canSubmit}` | 发送中禁用 | 消息错误态 | playground-empty-state | `playground-input.tsx` |
| 看日志 | 筛选按钮 searchLoading（fetchingLogs>0） | 表格骨架屏 | ErrorState/Alert 可重试 | EmptyState/EmptyTaskArtifacts | `usage-logs/components/common-logs-filter-bar.tsx`、`task-artifacts.tsx` |
| 充值 | 支付方式按钮选中态 + 单方法 loading + disabled | 金额计算 Skeleton | Alert「无支付方式」 | - | `features/wallet/components/recharge-form-card.tsx` |
| 看账单 | 订单历史按钮 | 列表 Skeleton | - | - | `features/wallet/components/dialogs/billing-history-dialog.tsx` |

- 全量扫描结果：`web/src/features/` 下所有 `size="icon"` 按钮 **0 处**缺 aria-label（脚本验证）。
- 图标均带 `aria-hidden="true"`；表单均用 FormLabel/htmlFor 关联；弹窗（Base UI Dialog/Drawer）内建 Esc 关闭 + focus trap + role=dialog。
- 结论：P1-5 目标中的「反馈/三态/a11y 键盘/焦点」基线已高度达标，无需大改。
