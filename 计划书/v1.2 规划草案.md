## v1.3 战略方向（P2，另行细化）

- 技能市场（N21）：SKILL.md 最小规范托管 + agent-skills-hub 正则扫描 + SkillSpector 式安全扫描；差异化=运行时沙箱 + 模型调用走网关计费 + key 平台托管
- Skill 进化闭环（N6）：SkillClaw 形态（relay 层拦截→会话摘要→聚合→发布门禁）
- 通用 webhook/事件子系统（N1）：5 个支付 webhook 归一为注册机制 + 幂等重放 + 双向状态机
- jsplugin 安全模型升级（N15/N17）：ExecutionGate 内容寻址一次性审批 + 分层权限 + Ed25519 插件写入签名；沙箱降级链 docker→Seatbelt→Bubblewrap→workspace
- CUA/沙箱增值（N17）：凭据保险库 + 流量令牌 + AutoPause 三件套；快照暂停/恢复
- 垂直任务模板（N19/N11）：Deep Research / 数学建模打包模板 SKU；生图渠道可靠性层
- /v1/pricing 稳定镜像端点（N17）：new-api 成定价源，锁定下游生态

## 明确不做（边界）

- 9router 式 MITM 拦截（合规风险）；nexus 60+ 策略枚举；aisix etcd 配置面；litellm Prisma 数据层
- AGPL/GPL 传染许可项目；医疗/法律/交易下单垂直（牌照问题）
