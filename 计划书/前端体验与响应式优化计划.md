## 1. Executive Summary
基于实测：项目已具备 Tailwind4 + 移动优先响应式基础与 Dark 主题，核心瓶颈是① 首屏 JS 4.2MB 拖垮 LCP、② 大屏(1440+)与触摸/安全区适配缺口、③ 无离线降级。计划分三阶段落地：**MVP（性能速赢 + 响应式补齐）→ Polish（设计 token 统一 + 无障碍/动效）→ Optimization（离线/图像/跨设备自动化）**，全程不重构、小步推进、每批可验收。

## 2. Responsive Strategy
- **断点策略**（沿用 Tailwind 默认，补两档）：
  - 已有：`sm 640 / md 768 / lg 1024 / xl 1280`
  - 新增：`2xl 1440`（大屏增强：多列表格列、卡片密度、管理台最大内容宽 `max-w-7xl`）
  - 补丁：`max-sm`（<640 触摸/安全区）按需补，目标从 ×3 → 覆盖底部导航/弹层/粘性操作条
- **移动优先**（保留）：理由——免费 API 站移动开发者/小屏访问占比高，现有 sm: 体系即是证据；桌面端用 `md/lg/2xl` 渐进增强
- **触摸与指针**：交互目标 ≥44×44px（列表行操作按钮/复选框）；hover 效果仅 `(hover:hover)` 下启用（`@media (hover:hover)`），避免触屏粘滞
- **安全区与动态视口**：弹层/底部导航加 `padding-bottom: env(safe-area-inset-bottom)`；移动端高度用 `100dvh`（键盘弹起不截断）；已 32 处 dvh 统一规范写法
- **字号/图片**：正文用流体字号 `clamp(15px, 0.875rem + 0.15vw, 16px)`；表格数字保持 `tabular-nums`；图片资源（logo/模型图标）加 `srcset` + `loading=lazy`，统一 `@/assets` 导出
- **陷阱**：不要在容器宽度上硬编码 px；避免桌面优先改造成回归移动端——所有改动在 375/768/1024/1440 四档验收

## 3. Performance Blueprint
- **目标（Core Web Vitals）**：LCP<2.5s、INP<100ms、CLS<0.1、动画 60fps
- **现状评估**：首屏 JS 1.2MB gzip（index）+ 若干 0.5-2.7MB gzip async 块；无 SW；低带宽环境 SPA 冷载 40s+
- **速赢（MVP）**：
  1. **路由级代码分割**：Rsbuild 已按路由拆 async——复查关键页（首页/控制台概览）首屏不再带重型 chunk；把登录/公开页从 admin bundle 剥离
  2. **图标 tree-shaking**：lucide-react 已按需导入——补 lint 防全量 `import * as Icons`
  3. **字体子集化**：中文字体按常用字子集（现有 Lora/Public Sans 已子集化则复核）
  4. **CLS 修复**：表格/卡片/弹层容器固定最小高（`min-h` 占位），图像给宽高比
- **长期**：
  - CSS containment：列表行/卡片 `content-visibility:auto + contain-intrinsic-size`（长列表/表格）
  - 动画 GPU：仅 `transform/opacity`（避免 top/left/width 布局动画）；`will-change` 克制使用
  - INP：长任务拆分（表格虚拟滚动已用 @tanstack/react-virtual——扩展至渠道/日志长表）；事件处理去重（debounce 搜索）
  - **Service Worker（新增）**：`@rsbuild` 插件生成 SW——precache 应用壳（index.html+核心 chunk），网络不可达时显示离线降级页；对 `/v1` API 不缓存
- **陷阱**：SW 一旦发布难以撤回，用 `self.skipWaiting + clients.claim` + 版本化缓存名；不要预缓存动态日志数据

## 4. Design System Specification
- **Token 架构**：Tailwind4 `@theme` 为唯一来源——把现有 `colors.ts` / `theme-radius.ts` 迁移为 CSS variables（`--color-*` / `--radius-*` / `--space-*` / `--ease-*`），JS 侧经 `theme-radius.ts` 读取保持兼容
- **调色板**：延续现有 light/dark 双调色板；语义色（primary/success/warning/danger/info）逐项校验 WCAG AA 对比（正文 ≥4.5:1，大文本 ≥3:1）；高亮/徽章同时用文字/图标双通道（A-F 徽章已符合）
- **间距**：8px 基准 scale `0.5/1/1.5/2/3/4/6/8/12/16`（Tailwind 默认即此，规范统一使用）
- **圆角**：`4px`(输入框/小元素) `6px`(按钮) `8px`(卡片) `12px`(弹层/底部栏) `16px`(大卡片/移动卡片)
- **阴影/层级**：3 档 `sm(1px/2px)` `md(4px/8px)` `lg(8px/16px)`；弹层 z-index 统一（Base UI 已有层管理，规范化叠加层）
- **动效**：时长 `150ms`(hover/反馈) `200ms`(输入聚焦) `300ms`(面板/抽屉) `400ms ease-out`(弹层/Modal)；缓动统一 `cubic-bezier(0.2, 0.8, 0.2, 1)`；全局 `@media (prefers-reduced-motion: reduce)` 关闭非必要动画（tw-animate-css 已带基础支持，补产品级校验）
- **图标/插画**：统一 lucide（已用）；新增插画沿用现有简洁线稿风格，不引入第二套体系
- **组件一致性**：`web/src/components/ui/*`（shadcn 风格）为唯一底层；业务组件只允许组合 UI 基元——审计遗留组件差异（间距/圆角/字号）对齐 token

## 5. UX/UI Pattern Library Plan
- **层级与扫读**：卡片头尾留白统一 `p-4 sm:p-6`；表格行高 `h-12`(桌面)/`h-14`(触摸)；关键操作按钮主次分明（primary 唯一）
- **反馈与 affordance**：全局 loading（已有 auto-skeleton 复用）；按钮 loading 态统一（icon + disabled）；微交互（hover 提亮 100ms、active 按压缩放 0.98）
- **导航**：移动端——顶部汉堡 + **底部 Tab 栏**（控制台/密钥/日志/我的，触摸友好）；桌面——侧边栏（已有）加**面包屑**（系统设置深层页）；管理员侧边栏已含 Web 防护入口（v1.2.31）
- **无障碍（WCAG 2.1 AA）**：
  - 对比度：语义色全量 AA 校验（工具：axe-core 接入 CI 扫描）
  - 焦点：统一 `focus-visible` 2px 高对比环；表格/弹层 Tab 可达（Base UI 已支持，补全覆盖检查）
  - ARIA：图标按钮补 `aria-label`（已有 CopyButton 等，审计补全）、弹层 `aria-modal`、表单错误 `aria-describedby`
  - 键盘：弹层 Esc 关闭、箭头键选择（下拉/日期选择器）
- **表单**：内联校验错误（输入框下方红字 + 图标，已有部分）；移动端 input type 正确（email/tel/number/search）、`enterkeyhint`
- **空态/边界**：统一 `EmptyState`（icon+文案+CTA）；错误态（网络/429/5xx）用 `getFriendlyErrorMessage` 人话 + 重试按钮；403 页已有；列表分页/搜索无结果提示
- **Motion 降级**：`prefers-reduced-motion` 下弹层直接显示、进度条变静态

## 6. Technical Architecture
- **栈保持**（推荐理由）：React19 + Rsbuild2 + Tailwind4 + Base UI/shadcn 已成熟，主题/i18n/路由体系就绪；换栈收益低风险高
- **组件结构**：保持 `features/` 组织；抽共享 hooks：`use-is-mobile/tablet/desktop`（matchMedia）、`use-motion-safe`、`use-focus-trap`（弹层复用）
- **主题系统**：CSS variables + `data-theme`（现有 theme-provider 强化为 token 单一来源；SSR/首屏防闪烁策略：`suppressHydrationWarning` + 内联初值）
- **CSS 策略**：utility-first（Tailwind）为主 + 少量 `@layer components`（复杂重复组件如 DataTable 容器）；禁止内联 style 布局
- **测试策略（响应式/UX）**：
  - 新增 Playwright：断点矩阵 `375/768/1024/1440` × light/dark，冒烟主路径（登录→控制台→密钥→日志）
  - 无障碍：axe-core 扫描关键页（无严重/严重违规）
  - 现有 vitest 保持（组件逻辑）
  - 性能：Lighthouse 预算门禁（LCP/CLS/INP 阈值断言）

## 7. Phased Rollout Plan
- **MVP（第 1-2 周，速赢）**：大屏 2xl 布局与容器宽度；max-sm 触摸/安全区补丁；首屏 JS 瘦身（vendor 复查 + 图标 lint + 关键路由分离）；CLS 占位修复 → 验收：LCP 实测下降、四档断点无溢出
- **Polish（第 3-4 周）**：token 统一（colors/radius 并入 @theme）；动效规范 + reduced-motion；axe 无障碍修复；表单/空态/面包屑统一；底部 Tab（移动）→ 验收：axe 无严重违规、dark 对比度 AA
- **Optimization（第 5-6 周）**：Service Worker 离线降级；图片 srcset/懒加载；长表虚拟滚动扩展；Playwright 跨设备矩阵 + 性能预算 CI → 验收：全矩阵绿、CWV 达标
