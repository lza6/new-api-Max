## `ops/` —— 运维与工程规范

| 文件 | 是什么 | 什么时候读 |
|---|---|---|
| `SOP-运维手册.md` | 速查命令、蓝绿部署与回滚、按症状的排障清单、事故响应流程、明令禁止的操作 | 任何线上排障 / 部署 / 回滚前 |
| `ADR-架构决策记录.md` | 从代码与注释逆向提取的关键架构决策（背景/决策/理由/后果+代价/证据 `file:line`） | 改架构相关代码前 |
| `黄金范例.md` | 本项目认可的写法清单 + 反面清单 | 写新代码前 / 代码审查时 |
| `token-billing-group.md` | 「token计费」分组的阶梯价、新增/改模型必须同步的 4 处、强制变更安全流程 | **改任何计费配置前必读** |
| `deploy-zero-downtime.example.sh` | 蓝绿零停机部署脚本的脱敏模板 | 了解部署流程时 |
| `disk-guard.example.sh` | 每日磁盘守卫脚本的脱敏模板 | 排查/预防磁盘增长时 |

> `*.example.sh` 是模板，**不是**可直接运行的脚本；真实版本在服务器上。
