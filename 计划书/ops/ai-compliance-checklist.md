# 生成式 AI 服务合规 Checklist（面向公众部署）

> 生成：2026-09-24 · 依据《生成式人工智能服务管理暂行办法》等监管要求整理。
> 用途：运营商「开箱部署」前的自查清单；非法律意见，具体以所在司法辖区监管为准。
> 本项目 README.zh_CN.md 已声明合规义务，本清单给出可操作步骤。

## 上线前必查

### 1. 资质与备案
- [ ] ICP 备案（域名 + 服务器所在省份，如中国境内）
- [ ] 生成式 AI 服务备案（如适用，向属地网信办）
- [ ] 算法备案（若使用境内可感知的生成算法，按《互联网信息服务算法推荐管理规定》）
- [ ] 增值电信业务许可（若涉及经营性信息服务/API 转售）

### 2. 内容安全
- [ ] 输入内容安全过滤（敏感词/违法内容拦截，可接内容安全 API）
- [ ] 输出内容安全过滤（生成结果二次校验）
- [ ] 未成年人保护（防沉迷/适龄提示，如适用）
- [ ] 违法有害信息举报渠道 + 处置机制（限时下架/封禁）

### 3. 实名与账号
- [ ] 用户实名认证（依规执行；本项目支持多种注册方式，运营者自行决定实名策略）
- [ ] 账号注册限制（防批量注册/滥用）
- [ ] 用户协议 + 隐私政策（公开可访问）

### 4. 日志留存
- [ ] 请求/响应日志留存（本项目 logs 表已具备，配置保留期）
- [ ] 用户操作审计日志（本项目 audit 中间件已记录，去敏不落敏感凭据）
- [ ] 日志访问权限控制（仅管理员）

### 5. 数据与隐私
- [ ] 隐私政策说明数据用途
- [ ] 用户数据删除机制（账号注销/数据清理）
- [ ] 密钥/凭据加密存储（本项目 argon2id 密码 + token 指纹）

### 6. 上游授权
- [ ] 确认上游模型服务授权允许转售/代理
- [ ] 保留上游服务条款与授权记录

## 运维持续
- [ ] 内容安全策略随法规更新
- [ ] 举报处置时效监控
- [ ] 日志保留周期与存储成本平衡
- [ ] 定期安全审计（参考 T8 ASVS 审计报告）
