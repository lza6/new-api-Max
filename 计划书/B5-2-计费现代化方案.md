# B5-2 计费现代化（微美元影子价 + tiered breakdown）方案（v1.2.28）

日期：2026-09-19
状态：设计定稿 → 实现

## 1. 目标
- 影子价：consume log 增加微美元口径 api_equivalent_usd（仅统计，不改变现有 quota 计费）。
- 费用明细 API + 前端费用解释卡消费（tier_matched/cache_ratio/completion_ratio/group_ratio 分段）。
- 安全：不得改变现有计费数值；只加口径字段；全量计费回归。

## 2. 现状（代码证据）
- consume log 统一入口：model/log.go RecordConsumeLog（L339-400），params.Other (*LogOther) 已带计费要素（model_ratio/group_ratio/completion_ratio/cache_ratio，log_info_generate.go GenerateTextOtherInfo L97-106）。
- 前端费用解释卡：B5-1 explain（facts/inferences）已在 usage-logs 详情实现；B5-2 补充微美元与 tiered 明细分段。
- Pricing（model/pricing.go L20-43）无直接 USD 单价字段；builtin_billing 仅 gpt-6-astra 一个表达式。
- quota 换算集中 common/quota_math.go（QuotaFromFloat/Checked/Round），影子价绝不经过 quota 换算。

## 3. 设计决策

### 3.1 影子价（api_equivalent_usd，微美元）
- 独立于 quota：内置 `modelShadowPrices` 表（模型 → {inputUsdPerM, outputUsdPerM}），来自公开 USD 定价；未收录模型 → 0（不估算，诚实）。
- `service.ComputeApiEquivalentUsd(model string, promptTokens, completionTokens int) (int64, bool)`：微美元 = (prompt×input + completion×output)/1e6 × 1e6，饱和 clamp 到 int64 安全界（复用 common 饱和思路，禁止溢出）；未知模型返回 (0,false)。
- 写入点：model/log.go RecordConsumeLog 内 `params.Other.SetPublic("api_equivalent_usd", usd)`（best-effort，Other 为 nil 则跳过）——所有 consume log 统一入口，零改造各 relay。
- **不改 quota**：RecordConsumeLog 不动 params.Quota 计算；影子价仅写 other 字段。

### 3.2 费用明细 API
- GET /api/log/usage/:id/cost-detail（UserAuth；Admin 可见全部，普通用户仅本人 log）
- 返回：{quota, model_ratio, group_ratio, completion_ratio, cache_ratio, tier_matched(来自 explain.facts), api_equivalent_usd(微美元)}。
- 前端费用解释卡消费（usage-logs 详情弹窗补充「影子价 + 计费分段」区块，复用现有 explain/Label 组件，i18n 双语）。

### 3.3 安全回归
- 断言：RecordConsumeLog 写入门禁场景（quota=123）前后 quota 数值不变，仅 other 增加 api_equivalent_usd。
- quota_math 既有测试全量跑（QuotaFromFloat/Checked/Round），确保未触碰换算链。

## 4. 三库兼容
- 只写 Log.Other JSON（无新列、无新表）→ 三库零风险；AutoMigrate 无变更。
