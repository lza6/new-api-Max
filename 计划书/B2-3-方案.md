# B2-3 实现方案（onboarding + 错误人话全覆盖）

## 目标
1. 首次登录引导：创建 Token → 模型广场 → 发起首次请求（3 步，全部可跳过）
2. 错误人话映射扩展到：渠道冷却 / 额度不足 / 模型暂不可用 / 上游限流 / IP 封禁
3. playground 错误显示人话解释（复用 getFriendlyErrorMessage）

## 现状（侦察结论）
- server-error-message.ts 已有 B6-2 五类：insufficient_quota / key_invalid / rate_limited / upstream / content_filter
- 缺口：渠道冷却（cooldown/cooling down）、IP 封禁（ip_banned，后端 web-protection 429 type=ip_banned）、模型暂不可用（model_not_found）
- onboarding 不存在；_authenticated/route.tsx 布局为挂载点
- playground 已有 MessageError 组件 + getMessageErrorState，可增强接人话

## 实现
### 1. 错误映射扩展（server-error-message.ts）
在 FRIENDLY_ERROR_PATTERNS 追加：
- /cooldown|cooling[_ ]?down/ → 渠道冷却人话
- /ip[_ ]?banned|ip banned/ → IP 封禁人话
- /model[_ ]?not[_ ]?found|model.*unavailable|no.*model/ → 模型暂不可用人话
顺序：额度 → 密钥 → 限流 → 冷却 → IP封禁 → 模型 → 上游 → 内容安全

### 2. onboarding 组件（features/onboarding/）
- localStorage key: newapi_onboarding_dismissed（登录用户 id 维度）
- 3 步卡片：Step1 创建 Token（/keys）、Step2 模型广场（/pricing）、Step3 发起首次请求（/playground）
- 全部可跳过（× 按钮 + 底部 Skip）；复用 Card/Button/Link 组件
- 挂载到 AuthenticatedLayout 主内容区顶部

### 3. playground 人话解释
- MessageError 的 errorState.content 若为非人话技术文本，用 getFriendlyErrorMessage 优先替换
- 保留原始 error 供 hover 展示（detail + 原始原因）
