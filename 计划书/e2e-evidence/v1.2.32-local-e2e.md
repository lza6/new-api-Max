# 本地真实 E2E 证据（v1.2.32 代码，2026-09-20）

环境：本地构建 new-api-e2e.exe（含 web embed），SQLite，MEMORY_CACHE_ENABLED=true，SYNC_FREQUENCY=5，
URL_GUARD_ALLOWLIST=localhost（第二道 SSRF 守卫为硬编码私网拦截，hostname 白名单是唯一放行方式），
模拟上游为本地 SSE 服务（首字延迟 1.5s）。

## 签到设置后端 E2E
PUT checkin_setting.enabled=true / min_quota=250000 / max_quota=400000；
GET /api/option/ 复读：min=250000（0.5 CNY @500000）、max=400000（0.8 CNY）、enabled=true。通过。

## 链路说明（排查记录）
- 400 model_price_error：模型未配置价格 → PATCH /api/option/model_pricing 配置 ModelPrice=0（需 expected_version）
- 500 ssrf guard 拦截 127.0.0.1：service/url_guard.go 硬编码私网 CIDR 不可配置 → URL_GUARD_ALLOWLIST=localhost + base_url http://localhost:3999（hostname 白名单）
- channel/token/option 接口形状：channel 包 {"channel":{...},"mode":"single"}；token 包 {"token":{...}} 且创建不返回 key（从本地库取）；option GET 为 [{key,value}]
- 内存缓存：启动日志 "memory cache enabled"、渠道增删 5s 内生效（SyncChannelCache）
