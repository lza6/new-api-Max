## T5 单密钥限速（rpm / qbs / 并发）

- 后端：`Token.RateLimit` JSON 字段（`{"rpm","qbs","concurrency"}`）+ `middleware.TokenRateLimit`（rpm=60s 滑动窗口、qbs=令牌桶按秒回填、concurrency=进程内信号量）+ 挂载到 /v1 与 /v1beta 路由
- 前端：密钥创建/编辑抽屉新增「RPM / QPS / 并发数」输入（空=继承全局/分组）
- 真实 E2E：
  - token1 设 `rpm:2` → 连发 3 次：200,200,429「已达到该密钥的请求速率限制（每分钟 2 次）」
  - token2 设 `concurrency:1` → 并发 5 请求：1 通过 + 4 个 429
- 单测：`TestAllowTokenQBS / TestTokenConcurrencyStore / TestTokenRateLimitConfigParsing`
