## 0. TL;DR（三句话结论）

1. **主项目定位确认**：new-api 是「渠道聚合 + 计费 + 限流 + 任务 + 日志透明」的 **Agent 网关**——参考集中大量 agent 平台/记忆/技能生态项目正是为它后期横向扩展（多模态、电商、PPT、办公、技能市场）准备的素材。
2. **最高价值可迁移点**（按投入产出）：① MCP 通道接入（Go 代理网关同构）；② 计费增强「成本可视化 + 上下文压缩/缓存节省」；③ 日志透明升级「日志治理 + 证据闭环」；④ 技能市场（检索/评估/进化）；⑤ 电商视频/短剧/办公横扩展。
3. **严格边界**：渗透/逆向/验证码对抗类仅防御视角研究（安全对照），**不进入产品功能**；严禁重构、严禁强推、三库验证、真实证据。

## 1. 主项目画像（识别结论）

- 技术栈：Go 1.25 + Gin + GORM v2（SQLite/MySQL/PG）；React19+TS+Rsbuild2+TanStack+Zustand+Base UI+Tailwind4；Redis+内存缓存；relaykit 独立模块。
- 能力：40+ 上游渠道聚合、模型路由、计费/限流、Web 防护、任务轮询（视频/图像）、JS 插件（Sobek）、健康探测/组合路由、SSE 任务事件、用户画像（规则版）、WebAuthn/TOTP/OAuth、日志透明化。
- 目标定位（用户口径）：让小白也能用 AI；打开黑匣子让用户边用边学；AI 更懂用户；沉淀用户自己的 skills；横向扩展图片/视频/电商/PPT/办公。
- 现状：v1.2.38；Go 测试 296 文件、前端测试 133 文件；三库验证已自动化基线未完全契约化。

## 3. 六大可迁移方向（对标 → 落点建议）

### 3.1 MCP 通道接入（高价值，低风险）
- 参考：smart-mcp-proxy__mcpproxy-go（Go MCP 代理）、modelcontextprotocol__servers（官方参考）、OWASP-MCP-Governance-and-Risk-Project（治理框架）、mcpstrike/token-optimizer-mcp。
- 可迁移点：MCP 代理与主项目"渠道聚合"同构——同一套计费/限流/鉴权复用；工具注册表 + 审批。
- 落点：`relay/` 新增 MCP 通道；`plugins/` 工具注册；管理台「MCP 工具」页。
- 优先级：P1（需 P0-1 三库契约套件垫底）。

### 3.2 计费增强：成本可视化 + 上下文节省（高价值）
- 参考：Sparrowgate（savings 注入 usage）、semantix（语义缓存/自适应调度/推测预取）、opencode-magic-context（无限上下文+压缩）、rtk（bash 输出压缩 60-90%）、token-optimizer/savior、hermes-quota-plugin（配额实时面板）、SolveaCX__tokentest.io（黑盒验证）。
- 可迁移点：任务日志/账单附带缓存命中、节省、耗时；计费透明化从"扣费"升级"额度可视化+成本分解"。
- 落点：`service/billing_usage.go`、`service/log_traffic.go` 增加节省/缓存字段；前端账单卡片。
- 注意：必须走 `common/quota_math.go` 饱和与 `pkg/billingexpr`，禁止裸转换。

### 3.3 日志透明升级：日志治理 + 证据闭环（高价值）
- 参考：Logic（日志源管理+实时检视）、hermes-hud（agent 思考可视化）、FankChen__tracecrate（trace 工作台）、hermes-trace（执行 trace 图）、openwiki（Grounded Claims 事实↔版本化源证据）、claude-md-doctor（规则↔会话历史回测）、reverify/sigmap（声明↔确定性核查）、vnx-orchestration（NDJSON 审计收据）、weir（OTel trace 安全 CI）。
- 可迁移点：request_id 全链路 + 错误归因（已有雏形）→ 升级为「日志治理 + trace 可视化 + 证据锚定」；审计日志不可篡改（append-only）。
- 落点：`middleware/` request_id 中间件、`service/relay_error_class.go` 扩展、前端日志详情页。
- 优先级：P0-4（已在下一步改进指南立项）→ 按本报告扩展证据闭环。

### 3.4 技能市场与技能进化（差异化，中高价值）
- 参考：Leon-Drq__openagentskill（技能决策层：resolve/信任信号/安装回执）、HKUDS__OpenSpace（技能检索/评估/进化）、SkillSpector（安装前安全扫描）、EvoSkill/SkillOpt（进化闭环）、kendex（skills-lock 版本化/回滚）、cc-polymath（渐进式技能发现）、kitter（按需技能）、mimik（浏览器工作流→skill）、tigerless-labs__autoharness（自学习技能）。
- 可迁移点：SKILL.md 单一事实源 + 多宿主渲染；技能安全扫描做上线门禁；技能进化吃网关真实会话数据；技能包版本化可回滚。
- 落点：`plugins/` + `pkg/jsplugin/` + 前端「我的技能」面板（装即锁版/变更预览/一键回滚）。
- 优先级：P2（需 jsplugin 安全模型升级垫底）。

### 3.5 电商/视频/办公横扩展（产品方向，中高价值）
- 参考：电商——BorderlessSKU（单源事实→多语多模态可审计素材）、coolqoo__1click-ecom-detailpage（一键主图/PDP）、ziguishian__MxPage（电商图文批量工作台）、anjaiahtinku（商品→可排期 TikTok 工作流）、malulile（运营文案品控）。
- 视频/媒体——MoneyPrinterTurbo（主题→成片全自动）、OpenMontage/calesthio（agentic 视频生产）、cs-board（白板视频全流程）、chatfire-AI__huobao-drama（短剧平台）、shuyu-labs__BigBanana（漫剧工场）、seedance-2.0（镜头规划 skill）。
- 办公——genspark-ai__genoffice（AI Office：Word/Excel/PPT/PDF）、ppt-master（文档→PPT）、dsh-univer-office（NL→表格+图表+实时预览）。
- 落点：视频任务渠道已具备（任务轮询/SSE）→ 增加「能力统一契约 + 产物完整性校验（时长/分辨率/音轨）+ 结算前 QA 门」；PPT/办公以「技能=工作流」方式接入任务系统。
- 优先级：P1-3（SSE 续传）完成后接 P1（电商视频流水线）。

### 3.6 任务编排与状态权威化（中高价值）
- 参考：mission-control（派发/检视/失败/花费/协调）、loopx（provider 无关状态控制面）、matterloop（可验证/可暂停/可恢复）、DSH-taskboard（SQLite 单一事实源）、sortie/openase/orbi（Issue→自动会话→PR）、plan-cascade（智能分解并行）、vnx-orchestration（NDJSON 收据+worktree 隔离）、crabfleet（Durable Object 卡片工作流+会话接管）。
- 可迁移点：任务表保证「权威+可恢复+可续跑」；加评审门/审批；花费跟踪；Issue/工单驱动。
- 落点：`service/task_*.go`、`model/task_event.go`、`controller/counting_writer.go`。
- 优先级：P1-2/P1-3（Redis 批量落库 + SSE 续传）之后。

- 严禁 -f 推送；以 main 为主；每个批次真实跑通留证据后才算 DONE。
