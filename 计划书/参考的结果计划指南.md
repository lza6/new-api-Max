### sub2api（未索引新目录，补读 README/README_CN）
- **定位**：AI API 网关平台 —— 订阅配额分发（Go1.27 + Vue3 + PostgreSQL + Redis，Docker 就绪，多语言 README）
- **可借鉴优点（与主项目差距）**：
  1. 「订阅账号池 → API 配额」分发模型：管理一组上游订阅账号（OAuth/API Key 类型），把订阅额度按量分发为下游用户 API Key——主项目目前按第三方 API Key 渠道计费，缺「订阅池内额度分发」能力（高差异化扩展方向）。
  2. 管理后台 iframe 外部系统集成（工单等）：轻量生态扩展模式，主项目可借鉴（如 iframe 嵌入帮助/工单/监控）。
  3. 多账号粘性会话与 Nginx 转发注意点（http 头下划线 session_id 会被 Nginx 丢弃）：运维细节值得记录。
  4. 商业化运营：多语言 README + 赞助商墙 + Claude Code/Codex/Gemini 工具接入生态（与主项目 B5-5 工具预设方向一致）。
- **合规提示**：README 明确声明订阅分发可能违反上游 ToS——主项目引入该模式需先评估合规与风控。
