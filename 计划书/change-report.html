new-api-Max 变更报告

生产：freeapi.tingfengai.art（Caddy→3000→PG/Redis）｜线上版本：v1.2.92｜日期：2026-09-22

一、上下文与直觉

这是一个已在生产的 AI API 网关（上游 New API 的分支 lza6/new-api-Max）。需求本质：
  • 把「订阅」做成可售卖的商业化能力：套餐定价、兑换/余额购买、并发与 RPM 档位、模型白名单、自动升级分组、到期降级；
  • 把「数据」变成网站权威性：每模型调用统计、流量智能单位、带宽排行、站点总带宽/请求/Token；
  • 把「体验」拉满：模型效果测试入卡、系统信息真实上报、前端中文汉化；
  • 把「交付」变可靠：生产热更新 SOP、敏感信息脱敏、真实 E2E 台账。
关键直觉：“能买的订阅必须真实生效”——所以逐条做了线上实证（429 文案、RPM 计数、分组升降级、billing_source=subscription 等），而不是“有代码就算完成”。

三、验证证据（节选）

  • 余额兑换：充值开关=false 时 POST /api/subscription/balance/pay → 200；扣 ¥2；source=balance；订单 success
  • 并发 3/s：同秒 3 个 200，第 4 个 429「基础并发请求已达上限（每秒 3 次）」
  • 订阅 RPM150：170 并发 = 3×200 + 147×订阅并发429 + 20×订阅RPM429（基础 429=0）
  • 管理员升档：PATCH tier rpm 150→200 → 170 并发 0 个 rpm429 → 复位
  • 矩阵越权：qwen-3.8-max → 403「不在当前订阅套餐」；deepseek → 200
  • 自动升级/降级：兑换后 group=subscriber；到期扫描后 group 回退 default
  • 费用类型：消费日志 billing_source:"subscription"
  • 产物实证：部署二进制 grep 命中 用户基础限速×1、Effect test×2、2026-09-18×2
  • 计费对账（v1.2.92 真实 E2E）：deepseek-v4-flash 按次，模型单价 0.001 × 分组倍率 0.1 → 消费日志 quota=50 = ¥0.0001/次；改价前 0.01×0.1=¥0.001/次（6 元仅 6000 次）→ 改价后 6 元可用 60000 次
  • 模型广场恢复按次：/api/pricing 返回 quota_type=1（按次）、model_price=0.001、group_ratio={default:0.1, subscriber:0.1}
  • 版本显示修复：仓库 VERSION 首次随 tag 同步为 v1.2.92，/api/status version=v1.2.92（此前因 VERSION 残留 v1.2.80 导致“系统维护”恒显旧版且检查更新永远有新版本）
